Capture and integrate project documentation as a `cac` framework capability, distinct from the skill-bundling work in v0.1.3-skill-and-configuration-bundling.

Unlike the `world-manager`/`campaign-manager` agent skills, which `cac bootstrap` deploys as verbatim packaged copies into a target project, `CLAUDE.md` and `AGENTS.md` are NOT captured or deployed that way — they stay project-specific documents a developer authors and edits directly, not framework-templated files `cac` overwrites on bootstrap.

Instead, `CLAUDE.md`/`AGENTS.md` become one component *described by* a broader documentation system this campaign introduces: a guide document (or set of guide documents) exposed through the `crypts-and-commits` MCP server, giving an agent session guidance on how to best author or update a project's own `CLAUDE.md`/`AGENTS.md` content - generated and integrated documentation the agent can consult, rather than a file it deploys.

Encounters under this campaign will work out the concrete shape of this: what a "guide" document is (a new packaged reference doc, a new `.sourcebook` object type, a new MCP tool surface, or something else), what it covers beyond CLAUDE.md/AGENTS.md guidance, and how it's authored/generated and kept current.
